## 4. 后端接口契约（设备端演示链路）

全部带设备令牌 `Authorization: Bearer <deviceToken>`；demo 系列接口**只有绑定 demo 账号（19900000000）的设备能访问**，其它设备 403。

| 接口 | 时机 | 请求 | 关键响应 |
|---|---|---|---|
| `GET /api/device/demo/stages` | 联网建协议后立刻 | — | `{stages:[{stageId,name,gradeRange,…}]}`（6 个） |
| `POST /api/device/demo/session` | 选完学段+性别 | `{stageId, gender:"男"\|"女"}` | `{sessionId, childId, childName, stageName, nextType}`（**201**） |
| `GET /api/device/session/next?sessionId=` | 二维码页按一下 + 每 10s 轮询 | — | `{completed:{parent,student,teacher}, nextType, nextLabel, needTeacherCode}` |
| `POST /api/device/submit` | 一份卷答完（**必须**，否则 session/next 一直让设备重做同一份卷） | `{sessionId, questionnaireType}` | — |
| `POST /api/device/demo/join` | 提交之后 | `{sessionId}` | `{code, url, path, expiresAt, missingRoles:[{role,label,who,desc,sample}], isNew}`（**201**） |

**手机侧（免登录，无需 token）**：

| 接口 | 说明 |
|---|---|
| `GET /api/demo/join?c=<加入码>` | 落地页查这场还缺哪些角色、已完成的是否灰掉 |
| `POST /api/demo/join/{role}` | 领角色 → 返回 JWT（**角色写死在凭证里**）+ 该卷题目 |
| `POST /api/demo/join/submit` | 免登录提交（题号必须属于该角色的卷，否则 400） |
| `POST /api/demo/join/void` | 「选错了」撤销本人刚提交的一份，释放名额 |

报告页：`/shared/report/<shareCode>`（只读、24h、可多人看、免登录）；报告码在**每份卷完成时**就生成。

## 6. 必须知道的坑（10 条，都是今天真踩的）

1. **禁止向 GitHub / 任何远端 push**（朋大大 08:44 明令）。服务器这边一律本地提交 + `scp` 交付。已写进 `AGENTS.md` §6 与 `MEMORY.md`。
2. **子代理会越界 commit/push** → 派活时明确"不许 git 操作"，事后逐个核对提交内容。
3. **`src/data/questionnaires/*/scoring.ts` 是死配置**（生产零引用），运行时走 `buildScoringConfig()`（按 `questionnaire.dimensions[].axes` 声明顺序取 axis1/axis2）。别拿 scoring.ts 当真值。
4. **真值表要按【文案名】索引，不能按 id** —— id 会随约定变，文案语义不会。按 id 索引的那份副本就是"过期真相"，会绿着骗人（今天在 `e2e-report-output.test.ts` 和 `risk-severity-direction.test.ts` 各出现过一次）。
5. **提交后必须验「干净 checkout」**：只看工作区绿不算数，要在干净 worktree 上跑测试。
6. **中性带维度在对比里必须跳过**：没有象限，硬写会生成"家长认为是""，孩子自评为"""这种垃圾文案。
7. **烧录第一次必须 `full`**：板子原来是 v1 分区表（app@0x100000），代码用 v2（app@0x20000、assets@0x800000）。只刷 app 会写错位置起不来；**assets 必须刷到 0x800000，否则中文还是空白**。
8. **Windows 烧录**：ps1 要 UTF-8 BOM（否则 PS 5.1 按 ANSI 解码，中文注释变乱码直接语法坏）；esptool v5 **没有 monitor 命令**（用 idf-monitor 或 scripts/serial-monitor.py）；串口是 COM 口。
9. **编译并发限死 2**（`CMAKE_BUILD_PARALLEL_LEVEL=2` in `scripts/idf-env.sh`）：这台机器只有 3.7G 内存，全速编译会 load 60 + swap 打满 + **整机重启**（10-31 崩过一次）。
10. **清理脚本有库名硬闸门**：目标库不是 `lzti_dev` 一律拒绝执行（防误删生产库）。三种模式：`hard` / `soft`（保留加入码）/ `expired`。
