# 内在结构养育体系

> 基于微信公众号「明信改变」杨莉及朋大大实践总结
> 更新：2026-07-22

---

## 一、核心理念

**核心主张**：学业问题的底层是心智，心神不稳，再多外力也只是治标不治本。

**内在结构养育**是一套育儿认知论和方法论，旨在帮助孩子在不同发展阶段发展出相应的心神能力，最终实现心神正、心神有力量的健康人格。

核心目标：**稳心神、固心神、强心神**

---

## 二、育儿初心：双向奔赴

育儿初心包含两个维度：**成全孩子** + **彼此滋养**。

### 轴一：成全孩子（5个层次）

| 层次 | 说明 |
|------|------|
| 热情与好奇心 | 成长的源动力，让孩子持续探索世界 |
| 识风险知进退 | 生存智慧，让孩子学会判断边界 |
| 抗挫折 | 内在韧性，让孩子面对困难时不崩溃 |
| 天赋与机遇 | 让孩子不辜负与生俱来的天赋、资源和机遇 |
| 享受其中 | 让孩子活出独特价值 |

### 轴二：彼此滋养

打破"父母单向付出"的误区，构建相互滋养的亲子关系：
- 放下控制欲 → 专注于成全孩子的独特性
- 孩子感受到接纳 → 获得安全感，更愿意向父母敞开
- 父母获得价值感 → "被需要" + "共同成长"的幸福感

## 三、内在结构的6个组成部分

孩子内在结构由以下6个部分构成，这些部分相互关联、相互作用，共同决定个体的心理动力、行为模式及生命状态。

| 序号 | 组成部分 | 说明 |
|------|-----------|------|
| 1 | **有机体本能反应** | 人作为有机体自然产生的冲动、情感、愿望等（如生理需求、心理需求、分离个体化冲动及社会化愿望）。这是内在结构的原始动力部分，其健康与否直接影响个体的内在状态 |
| 2 | **内化客体（父母/外界的态度）** | 个体在与外界接触中，内化了父母或外界对自己本能反应的态度（如接纳、支持、批判或否定）。这种内化决定了个体对自我本能反应的态度，是内在结构形成的关键影响因素 |
| 3 | **自我意向（自我认知）** | 个体对自我的认知和感知，包括自我意向的正向（和谐、有准绳）或负向（差、纠结、虚假自我）。它是个体对本能反应和外界态度整合后的心理呈现 |
| 4 | **防御与妥协机制** | 个体为应对内在冲突或外界压力，在心理层面形成的应对策略，包括对内的防御（如压抑、否认、理性化）和对外的妥协（如虚假自我、讨好）。这部分决定个体能否有效掌管自己的本能反应 |
| 5 | **心神状态（掌管能力）** | 个体心神对内在冲突的掌控能力，即心神是否被本能反应或防御机制淹没，能否发展出强而有力的掌管能力。这决定个体是处于健康、有力量、少冲突的状态，还是处于情绪化、无力、冲突的状态 |
| 6 | **基于准则的价值与意义** | 个体行事所依据的准则，所坚守的价值，所感知的人生意义。这是内在结构的价值基石，为人生提供方向感和内驱力 |

> 健康的内在结构，能将外界信息转化为滋养心神的养分。

## 四、十大心神能力（敏感发展阶段）

十大心神能力是基于客体关系理论、埃里克森心理社会发展阶段论及临床实践总结出的，旨在助力孩子在不同发展阶段发展出相应的心神能力。

**关键特点**：层层递进，每一层能力的发展都建立在前一层的基础之上。

| 序号 | 能力 | 发展阶段 | 核心内涵 |
|------|------|----------|----------|
| 1 | 安全感 | 0-6个月 | 底层安全感是孩子无论发生什么都能安稳应对的基底，是心神发展的基础 |
| 2 | 营养足 | 3个月-会走 | 心神营养足能够让孩子拥有内外富足的心理基础，为后续发展提供能量 |
| 3 | 主体感 | 会走-上幼儿园之前 | 主体感强让孩子拥有"我能"的信心和力量，建立自我效能感 |
| 4 | 现实感 | 会走-学前 | 现实感强是孩子能处理好事情的前提，帮助孩子建立对客观世界的认知 |
| 5 | 主动 | 幼儿园阶段 | 心神能主动是孩子内驱力的原点，激发孩子探索和参与的积极性 |
| 6 | 真实客体之爱 | 幼儿园阶段 | "真实客体之爱"是孩子能处理好人际关系的密钥，帮助孩子建立健康的客体关系 |
| 7 | 生产勤勉 | 小学低年级 | 心神有"生产勤勉"感，孩子才可能勤奋，培养对学习和任务的投入感 |
| 8 | 胜任力感 | 小学高年级 | 胜任力感是优秀的基石，让孩子在学业和生活中建立自信 |
| 9 | 基于规划与掌管力的心理韧性 | 初中阶段 | 规划与掌管力是孩子学业能力强的核心，在此基础上形成容忍过程、相信努力的心理韧性 |
| 10 | 有基于准则、价值与意义的三观 | 高中阶段 | 心神有基于准则、价值与意义的三观，为孩子人生提供心锚，赋予持久的内驱力 |

## 五、五大心理营养要素

五大心理营养要素是支撑心神发展的养分：

| 要素 | 含义 |
|------|------|
| 自主 | 独立做出选择并为之负责 |
| 实事求是 | 尊重现实，不自欺欺人 |
| 自我负责 | 为自己的情绪和行为负责，不归咎他人 |
| 建设性 | 面向解决方案而非破坏性表达 |
| 同情心 | 对自己和他人都有慈悲心 |

## 六、四大推力原则

内在结构发展的四大推力：

| 原则 | 说明 |
|------|------|
| 分离个体化 | 与养育者分离，形成独立自我 |
| 与现实相洽 | 尊重现实，不过度理想化也不过度贬抑 |
| 撑起内在空间 | 有能力承受情绪而不被淹没 |
| 双向沟通通道 | 能表达需求也能倾听他人 |

## 八、家长角色定位

**不是"主导者"**：不觉得自己能"设计"孩子的未来，不把孩子当成期待的作品

**不是"旁观者"**：不什么都不管，静待花开，孩子需要物质和心理上的"营养"

**而是"守护者"和"滋养者"**：

| 角色 | 职责 |
|------|------|
| 守护者 | 保证自己不破坏孩子的可能性 |
| 滋养者 | 用正确的支持和心理营养，帮他把可能性变成现实 |

## 九、爱的四个基本要素（弗洛姆）

| 要素 | 含义 |
|------|------|
| 关心 | 对所爱对象生命与成长的积极关注 |
| 责任 | 自愿的对他人需求的回应 |
| 尊重 | 顺应所爱对象的自身成长规律，不将其当作工具 |
| 了解 | 深入本质，以关心为动力 |
