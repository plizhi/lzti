# 荔枝派·学习状态评估体系·综合介绍

> 基于「内在结构养育」理论的学习状态评估工具
> 更新：2026年7月


## 一、测评的初心：为什么需要这套工具

### 一个真实的困境

很多家长都有这样的困惑：

- 孩子成绩下滑，是态度问题还是能力问题？
- 孩子看起来挺用功的，但为什么效率不高？
- 孩子一到考试就焦虑，怎么帮他？
- 孩子好像对什么都没兴趣，怎么引导？
- 和孩子沟通越来越困难，不知道他在想什么

面对这些问题，家长的第一反应往往是"怎么解决"——补课、监督、说教、施压。但这些方法常常效果不好，甚至让亲子关系越来越紧张。

**内在结构养育**给了我们一个完全不同的视角：**孩子外在的学习表现，只是内在结构的外显。不看到结构，只纠正行为，就像树叶黄了就擦绿叶素——治标不治本。**

### 这套测评要解决的核心问题

**帮助家长从"内在结构养育"的视角，看见孩子当前的心理结构建设进度，看见自己和孩子在认知上的差异，看见老师在学校的观察——三双眼睛看到的画面拼在一起，才是孩子完整的状态。**

在此基础上，给出具体的养育建议——不是"你应该怎么做"的说教，而是"基于孩子当前的结构状态，下一步可以往哪个方向引导"的路径。


## 二、测评的理论根基：内在结构养育

### 核心主张

**养育的目标不是塑造孩子的外在表现，而是帮助孩子建立起支撑一生的内在心理结构。**

这套理论认为，孩子从小学到高三的12年，不是在"学知识"，而是在完成六个内在结构的建设。就像盖房子需要先打好地基、再立柱子、再砌墙——每个阶段都有它该完成的"结构工程"。错过了，后面的结构就不稳。

### 六个关键结构与对应的学段

| 学段 | 要建立的内在结构 | 建成后是什么样 |
|:---|:---|:---|
| 小学低年级（1-2年级） | **勤勉感** | 孩子相信"我能通过努力把一件事做好"，对学习有好感 |
| 小学高年级（3-6年级） | **胜任感** | 孩子相信"我通过方法和练习能让自己变厉害"，有自己投入的方向 |
| 初中（初一初二） | **自我管理结构** | 孩子能统筹多门功课，有自己的目标和规划 |
| 初三 | **压力整合结构** | 在目标和压力下，能把已有能力转化为实战表现 |
| 高中（高一高二） | **意义结构** | 了解自己、接纳自己，学习的动力转向"为自己而学" |
| 高三 | **选择与承担结构** | 能做出自己的选择，在重要关系中保持独立又保持连接 |

### 测评与内在结构养育的关系

这套测评，本质上是一套**"内在结构体检"工具**。就像体检报告告诉你身体各项指标的状态，这套测评告诉家长：孩子当前在关键内在结构上的建设进度如何——哪里已经建好了，哪里还需要加固。

**内在结构养育的"一个核心问题"**，贯穿整个测评的设计：

> **面对孩子的任何表现，先问：这对他正在建立的内在结构，是加固还是削弱？**

*   孩子考好了，你说"你真聪明"——加固了"能力是天生的"信念，削弱了"方法有用"的胜任感。
*   孩子考好了，你说"你这次用的方法很有效"——加固了"方法能让事情变容易"的胜任感。
*   孩子玩游戏玩得好，你骂他"不务正业"——可能削弱了他在某个领域已经建立的胜任感。
*   孩子玩游戏玩得好，你先认可他的能力，再引导他思考"你是怎么玩得这么好的？这里面有没有什么方法可以迁移到学习上？"——保护了胜任感，同时打开了迁移的可能。

测评的设计，就是帮助家长在面对孩子的具体表现时，能做出加固结构的选择，而非削弱。


## 三、测评的核心设计

### 3.1 六个学段，各自独立的评估维度

不是把同一套题目换个标题给不同年级用。每个学段有专属的评估维度和题目，精准匹配该阶段的发展任务。

| 学段 | 评估维度 |
|:---|:---|
| 小学低年级 | 学习兴趣、基础习惯、情绪适应 |
| 小学高年级 | 自我效能、成长指向、自我滋养 |
| 初中非毕业班 | 多任务管理、目标规划、学业归因、情绪韧性 |
| 初三 | 策略整合、目标锚定、反馈利用、心态稳定 |
| 高一高二 | 自我认知、方向探索、学业策略、支持连接 |
| 高三 | 决策清晰度、目标行动力、压力韧性、关系自主 |

### 3.2 三方视角交叉验证

同一个维度，三份问卷各自独立设计。不是同一套题换主语，而是每个角色基于自己能观察到的场景来作答。

- **学生卷**：报告自己内心的真实感受和信念——"我觉得……""我会……""我相信……"
- **家长卷**：基于在家庭场景中能直接观察到的具体行为——"孩子和我说起过……""我看到孩子……"
- **教师卷**：基于在课堂和校园中能观察到的表现——"该生在课堂上……""该生在作业中……"

三方数据的重合度和差异点，本身就是最有价值的发现。

### 3.3 双轴四象限模型

每个维度不是简单地给出一个分数或等级。而是用两个独立的轴来定位，四个象限对应四种典型状态。每种状态都有具体的画像、核心需求和养育建议。

举例：初中"多任务管理"维度

| | 执行度高 | 执行度低 |
|:---|:---|:---|
| **条理性高** | **统筹兼顾型**：有计划，也能执行 | **纸上谈兵型**：有计划，但执行跟不上 |
| **条理性低** | **野蛮生长型**：没计划，但肯花时间 | **随波逐流型**：没计划，也难执行 |

家长看到的不是"你的孩子多任务管理能力65分"，而是"你的孩子目前属于纸上谈兵型——他能做出很好的计划，但执行时常需要外部推动。下一步可以尝试：把日计划缩小到只规划接下来1小时，用完成感带动后续行动。"

### 3.4 全正向基调

所有题目从成长、收获、投入的积极体验切入。不给孩子贴负面标签——"拖延""懒惰""三分钟热度"——这些词不会出现在问卷里。保护孩子正在建立的内在结构，比指出问题更重要。


## 四、测评能带给家长什么

### 4.1 看见"看不见的结构"

成绩是看得见的，但支撑成绩的内在结构——信心、方法、方向、心态——常常被忽略。这套测评让这些"看不见的结构"变得可视化。家长拿到报告，看到的不是"我的孩子数学不好"，而是"我的孩子目前还没有建立起'通过方法可以让事情变容易'的信念——所以他遇到难题时容易放弃，不是懒，是结构还没建好。"

### 4.2 看见"我不知道的他"

很多家长在陪孩子做完亲子综合报告后，最大的感受是："原来他是这么想的。"孩子可能比自己以为的更有方向感，可能比自己以为的更在意成绩，可能在自己没注意到的地方偷偷努力。亲子视角的对比，往往是最触动家长的部分。

### 4.3 看见"下一步可以做什么"

报告不只是描述现状，更给出具体的养育建议。每种状态都有"画像→核心需求→家长怎么做"的完整路径。家长拿到报告，知道往哪个方向走。

### 4.4 体验"亲子间的双向滋养"

内在结构养育的目标，不是单向地"培养孩子"，而是构建彼此滋养的亲子关系。当家长学会从结构视角去理解孩子，当孩子的胜任感被保护、被加固，亲子关系就从"监督与被监督"变成了"共同成长"。这套测评，是这个转变的起点。


## 五、产品结构

### 5.1 每个学段包含

| 产品组件 | 数量 | 说明 |
|:---|:---:|:---|
| 测评问卷 | 3套 | 学生自评卷 + 家长观察卷 + 教师评价卷 |
| 测评报告 | 3份 | 家长单独版 + 亲子综合版 + 家校三方版 |
| 分享海报 | 3张 | 家长专属海报 + 亲子成长海报 + 教师沟通海报 |

### 5.2 测评流程

```
家长完成家长卷 → 获得第一份报告 + 家长专属海报
        ↓
孩子完成自评卷 → 系统合并数据，生成亲子综合报告 + 亲子成长海报
        ↓
（可选）邀请教师完成教师卷 → 生成家校三方综合报告 + 教师沟通海报
```

### 5.3 快速筛查版

每个学段提供快速筛查版（1-2分钟），作为完整版测评的体验入口。

### 5.4 全年成长服务

内在结构的建立不是一次性的。全年成长服务包括：
- 12个月内多次复测，用连续数据描绘成长曲线
- 家长、学生、教师三方视角持续追踪
- 每学期分阶段的养育调整方案


## 六、面向不同用户的介绍要点

### 6.1 面向家长

**一句话**：这套测评帮您看见孩子学习状态的真实画像——不只是成绩，更是他的信心、方法、方向和心态。

**核心打动点**：三份报告让您看到孩子的内心、老师的观察和您自己的视角。亲子视角的对比，往往是最触动的部分。

### 6.2 面向教师/学校

**一句话**：用最少的时间，获得每个学生在学习状态上的精准画像。

**核心打动点**：教师卷仅需5-8分钟，快速版仅2分钟。家校三方报告为家校沟通提供客观的对话基础。

### 6.3 面向渠道（银行私行、保险公司）

**一句话**：为高净值家庭提供科学、专业的孩子学习状态评估——不是一次性的讲座，而是一套可以持续追踪、持续服务的产品体系。

**合作方式**：测评作为客户权益赠送，报告解读作为沙龙主题，全年服务作为高端增值服务。

### 6.4 面向教育机构

**一句话**：精准定位每个学员的学习状态瓶颈——不是知识层面的薄弱，而是信心、方法、方向层面的深层问题。

**合作方式**：测评作为引流产品、入学评估工具或学员成长档案的一部分。

### 6.5 面向网络达人

**一句话**：不是一个产品推广，而是一个内容金矿。每个维度、每种状态、每个亲子差异的案例，都可以生成一篇高质量的内容。


## 七、项目背景

### 理论基础与作者

这套测评的理论根基是**"内在结构养育"**——一套由**朋大大与杨莉老师**共同创立的育儿方法论。

杨莉老师拥有多年心理学专业背景。2015年，她基于萨提亚心理学模式出版了《相信改变会发生——养育一个完整而富有灵性的孩子》一书。当他们的孩子于2023年以裸分考入清华大学时，杨莉老师与朋大大在回望中深切感受到育儿认知上更深层的突破——真正支撑孩子走过十几年求学路的，不是某一种技巧，而是孩子内部长出的、稳固的心理结构。

于是，他们将这套经过十多年生活检验的养育智慧，系统地整理成形，命名为**"内在结构养育"**。这套测评，正是这套理论在产品层面的落地。
