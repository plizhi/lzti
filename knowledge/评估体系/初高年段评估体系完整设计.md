## 二、初三大（初三）

### 核心能力
基于规划能力的心理韧性

### 7个维度

| 维度 | 核心问题 | 四象限 |
|------|----------|--------|
| **压力应对** | 面对压力，是转化还是被压垮？ | 从容转化型 / 焦虑紧绷型 / 压抑忽视型 / 崩溃无力型 |
| **时间规划** | 有计划吗？计划能执行吗？ | 高效自律型 / 有计划无行动型 / 随缘被动型 / 冲动混乱型 |
| **归因风格** | 如何解释自己的成败？ | 成长内归因型 / 外归因型 / 自责型 / 僵化型 |
| **情绪自稳** | 压力下情绪能否快速恢复？ | 坚韧恢复型 / 波动起伏型 / 压抑隔离型 / 脆弱崩溃型 |
| **意义感知** | 能感受到学习本身的乐趣和意义吗？ | 意义感知型 / 成绩导向型 / 被动接受型 / 意义无感型 |
| **自我价值感** | 对自己的价值有多确定？ | 内在笃定型 / 外在依赖型 / 自我怀疑型 / 价值混乱型 |
| **家庭归属感** | 在家里感觉安全、被接纳吗？ | 温暖型 / 疏离型 / 压抑型 / 冲突型 |

### 维度说明

#### 压力应对
- **从容转化型**：能把压力转化为动力
- **焦虑紧绷型**：压力大但能承受
- **压抑忽视型**：不承认压力，假装没事
- **崩溃无力型**：被压力压垮

#### 时间规划
- **高效自律型**：有计划且能执行
- **有计划无行动型**：会计划但拖延
- **随缘被动型**：没有计划，走一步看一步
- **冲动混乱型**：没有计划，行动冲动

#### 归因风格
- **成长内归因型**：成功归因于努力，失败归因于方法
- **外归因型**：成功归因于运气，失败归因于外部
- **自责型**：失败后过度自我责怪
- **僵化型**：归因方式固定，不灵活

#### 情绪自稳
- **坚韧恢复型**：情绪波动后能快速恢复
- **波动起伏型**：情绪波动大但能恢复
- **压抑隔离型**：情绪被压抑，不表达
- **脆弱崩溃型**：情绪波动后难以恢复

#### 意义感知
- **意义感知型**：能感受到学习本身的乐趣
- **成绩导向型**：学习就是为了成绩
- **被动接受型**：不知道为什么学，但愿意学
- **意义无感型**：完全感受不到学习意义

#### 自我价值感
- **内在笃定型**：自我价值来自内在认同
- **外在依赖型**：需要外界认可才能感到有价值
- **自我怀疑型**：经常觉得自己不够好
- **价值混乱型**：不确定自己的价值在哪里

#### 家庭归属感
- **温暖型**：家庭氛围温暖，感到被接纳
- **疏离型**：与家人情感距离远
- **压抑型**：家里气氛压抑，不敢表达
- **冲突型**：经常与家人发生冲突

## 三、高一高二

### 核心能力
意义与价值感的建立

### 7个维度

| 维度 | 核心问题 | 四象限 |
|------|----------|--------|
| **自我认知** | 了解并接纳自己吗？ | 清晰接纳型 / 认知模糊型 / 自我否定型 / 理想化型 |
| **方向探索** | 有想做的事吗？行动上探索了吗？ | 积极探索型 / 有想法无行动型 / 被动等待型 / 方向迷茫型 |
| **意义建构** | 如何理解学习的意义？ | 意义建构型 / 功利型 / 表层型 / 意义迷失型 |
| **支持感知** | 能感知并利用身边支持吗？ | 敏锐利用型 / 有支持不自知型 / 孤立型 / 过度依赖型 |
| **学业策略** | 如何应对学业挑战？ | 灵活调节型 / 苦撑型 / 被动应付型 / 策略缺失型 |
| **自我价值感** | 对自己的价值有多确定？ | 内在笃定型 / 外在依赖型 / 自我怀疑型 / 价值混乱型 |
| **过渡适应** | 入学后适应得怎么样？ | 顺利过渡型 / 缓慢适应型 / 适应困难型 / 持续抗拒型 |

### 维度说明

#### 自我认知
- **清晰接纳型**：了解并接纳自己的优劣势
- **认知模糊型**：不太清楚自己是什么样
- **自我否定型**：只看到缺点，忽视优点
- **理想化型**：对自己有不切实际的想法

#### 方向探索
- **积极探索型**：主动探索兴趣和方向
- **有想法无行动型**：有想法但不行动
- **被动等待型**：等别人告诉自己该做什么
- **方向迷茫型**：完全不知道想要什么

#### 意义建构
- **意义建构型**：能主动建构学习的意义
- **功利型**：学习是为了实际好处
- **表层型**：只看到表面，不深入思考
- **意义迷失型**：完全感受不到学习意义

#### 支持感知
- **敏锐利用型**：能敏锐感知并利用支持
- **有支持不自知型**：身边有支持但感受不到
- **孤立型**：不寻求也不接受支持
- **过度依赖型**：过度依赖某一个人的支持

#### 学业策略
- **灵活调节型**：有多种策略，能灵活调整
- **苦撑型**：方法单一，只会死撑
- **被动应付型**：不主动想办法
- **策略缺失型**：完全不知道怎么学

#### 自我价值感（同初三大）

#### 过渡适应
- **顺利过渡型**：快速适应新环境
- **缓慢适应型**：需要时间但最终适应
- **适应困难型**：一直感觉难以适应
- **持续抗拒型**：始终无法接受新环境

## 四、高三

### 核心能力
选择与承担——将意义与价值感付诸实践

### 4个维度

| 维度 | 核心问题 | 四象限 |
|------|----------|--------|
| **决策清晰度** | 能做出选择吗？选择是自己想的吗？ | 笃定自主型 / 方向明确被动型 / 积极探索型 / 迷茫回避型 |
| **目标行动力** | 有目标吗？为目标做了什么？ | 知行合一型 / 有目标无行动型 / 光想不动型 / 行动强迫型 |
| **压力韧性** | 高压下能保持稳定吗？ | 坚韧稳定型 / 表面平静型 / 焦虑隐忍型 / 脆弱崩溃型 |
| **关系自主** | 与重要他人的关系是否健康？ | 关系健康型 / 依赖型 / 疏离型 / 纠缠型 |

### 维度说明

#### 决策清晰度
- **笃定自主型**：方向清晰，是自己的选择
- **方向明确被动型**：有方向但是别人安排的
- **积极探索型**：还在探索，但态度积极
- **迷茫回避型**：不知道想要什么，逃避选择

#### 目标行动力
- **知行合一型**：有目标并付诸行动
- **有目标无行动型**：有目标但不行动
- **光想不动型**：想得多做得少
- **行动强迫型**：一直在动但没有方向

#### 压力韧性
- **坚韧稳定型**：高压下保持稳定
- **表面平静型**：表面平静但内心焦虑
- **焦虑隐忍型**：焦虑但不说，默默承受
- **脆弱崩溃型**：高压下容易崩溃

#### 关系自主
- **关系健康型**：与家人关系良好，能独立也能依赖
- **依赖型**：过度依赖父母或某人
- **疏离型**：切断或回避重要关系
- **纠缠型**：与家人关系界限模糊

## 五、组合分析

### 高风险组合

|------|------|------|----------|

| 压抑型 + 自我怀疑型 | 🔴高 | 家庭压抑 + 自我否定 | 改善家庭沟通，建立自我认同 |
| 疏离型 + 孤立型 | 🔴高 | 家庭和学校都感受不到连接 | 需要系统性干预 |
| 自我怀疑型 + 自我否定型 | 🔴高 | 双重否定，极度不自信 | 需要专业心理支持 |
| 价值混乱型 + 方向迷茫型 + 意义迷失型 | 🔴高 | 三重迷失 | 系统性干预，从建立价值感开始 |

### 中风险组合

| 组合 | 风险 | 表现 | 指导方向 |
|------|------|------|----------|
| 有计划无行动型 + 功利型 | 🟡中 | 会计划但不做，学习为了分数 | 建立计划执行机制，连接学习与成长 |
| 方向明确被动型 + 表层型 | 🟡中 | 有方向但不是自己的 | 协助探索内心真实意愿 |
| 认知模糊型 + 被动等待型 + 孤立型 | 🟡中 | 不了解自己、被动等、有支持不用 | 主动引导自我探索，鼓励利用支持 |
| 苦撑型 + 外在依赖型 | 🟡中 | 只会硬学，靠别人认可 | 肯定努力，同时帮助建立内在价值 |

### 理想组合

| 组合 | 表现 | 保护重点 |
|------|------|----------|
| 从容转化型 + 高效自律型 + 成长内归因型 + 坚韧恢复型 | 压力下保持冷静，有计划能执行 | 保持现状，避免过度干预 |

| 温暖型 + 内在笃定型 | 家庭支持建立稳定的自我价值感 | 保持现状 |

## 九、问卷测量设计

### 核心问题与解决方案

| 问题 | 说明 |
|------|------|
| 社会期望效应 | 学生选择"正确答案"而非真实情况 |
| 行动一致性难以自测 | 学生可能高估自己 |
| 某些维度效度存疑 | 信念与行为常不一致 |

### 解决方案

#### 1. 行为锚定题（非抽象自评）

| 原来的问法 | 改进后的问法 |
|------------|--------------|
| "你能及时完成作业吗？" | "上周你有多少次作业是在截止时间前完成的？" |
| "你相信自己能达到目标吗？" | "遇到困难时，你通常会怎么做？" |

**改进方式**：用具体行为题替代抽象自评题

#### 2. 三角验证（多视角）

| 问卷类型 | 优势 | 局限 |
|----------|------|------|
| **孩子自评** | 了解主观感受 | 可能美化 |
| **家长评价** | 看到行为表现 | 可能主观 |
| **老师评价** | 看到课堂表现 | 视角有限 |

**改进方式**：同一维度从三个视角提问，交叉验证

#### 3. 反向题检测一致性

**问法示例**：
- 正向："我通常能按计划完成任务"
- 反向："有时候会拖延到最后一刻才做"（选同一方向说明一致）

**改进方式**：设计反向题检测回答一致性

#### 4. 强迫选择题

**问法示例**：
- A. "我会主动制定学习计划，并坚持执行"
- B. "我通常跟着老师的要求走，没有自己的计划"

**改进方式**：在两个同等可能的选项中强迫选择，减少"两边都选"的模糊答案

#### 5. 情境题（情境模拟）

**问法示例**：
"数学考试还有一周，你有一道完全不会的题。你会怎么做？"
- A. 立刻问老师或同学
- B. 先自己思考，实在不会再问

**改进方式**：用具体情境题替代直接询问，捕捉真实反应

### 具体示例：目标行动力维度

#### 原来的问卷题
- "你通常能完成自己设定的目标吗？"

#### 改进后的问卷题

**孩子自评（情境+行为）**：
1. "这周你为自己的目标做了哪些事？"（开放行为题）
2. "遇到困难时，你会坚持下去吗？"（行为锚定）

**家长评价（行为观察）**：
1. "孩子说到的事情，通常能做到吗？"
2. "孩子有目标时，会不会主动采取行动？"

**老师评价（课堂表现）**：
1. "这个学生在讨论未来目标时，表现得有多清晰？"

## 十、发展路径预测

### 报告板块

| 板块 | 内容 |
|------|------|
| **当下位置** | 当前各维度的状态描述 |
| **变化趋势** | 相比上次测评，哪些维度变好了，哪些退步了 |
| **轨迹预测** | 基于当前状态，预测发展方向 |
| **关注建议** | 这次测评最需要关注什么 |

### 变化类型

| 变化类型 | 说明 |
|----------|------|
| **↑提升** | 比上次更好，需要继续保持 |
| **→稳定** | 状态稳定，无需特别干预 |
| **↓预警** | 比上次退步，需要关注 |
| **⚠️显著预警** | 急剧下降，需要重点干预 |
