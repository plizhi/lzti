# 用户体系和激励规则 v1.0

> 更新日期：2026-09-20

---

## 一、用户类型

| 用户类型 | 判断标准 | 测评次数 | 说明 |
|:---|:---|:---:|:---|
| **Pending** | 从未购买过订阅 | 1次 | TR券，15天有效 |
| **Active** | 订阅在有效期内（status='active' && expiresAt > now） | 12次/年 | 年度订阅用户 |
| **Expired** | 订阅已过期 | 0次 | 需续费 |

### Pending 用户特征
- 来源：nzyy.cc 跳转 / 直接注册
- 状态：无手机号密码（待补充）/ 无订阅记录
- 权限：仅1次试用测评（TR券）
- 可参与：分享邀请激励体系

### Active 用户特征
- 来源：Pending 用户购买订阅后升级
- 状态：Subscription.status='active' && expiresAt > now
- 权限：12次/年测评次数
- 权益：订阅延长、积分兑换

## 二、激励体系

### 2.1 推荐奖励（通用）

| 场景 | 推荐人获得 | 说明 |
|:---|:---:|:---|
| 被推荐人注册 | +5积分 | |
| 被推荐人完成测评 | +3积分 | |
| 被推荐人订阅（推荐人已是Active） | +1个月订阅期 + 1次测评 | 延长订阅期 |
| 被推荐人订阅（推荐人是Pending） | TR券（+1次测评机会） | 15天有效 |

### 2.2 积分兑换

| 产品 | 所需积分 | 权益 |
|:---|:---:|:---|
| 荔心卷（LX） | 10积分 | 单次完整测评，3个月有效 |
| 荔升卷（LS） | 15积分 | 单次+趋势追踪，3个月有效 |

### 2.3 Trial 券（TR）

| 触发场景 | 获得者 | 有效期 | 权益 |
|:---|:---|:---:|:---|
| Pending用户注册成功 | 立即获得 | 15天 | 1次完整测评 |
| 被推荐人订阅（推荐人是Pending） | 推荐人 | 15天 | 1次完整测评 |

## 四、次数扣减优先级

测评次数使用时，优先顺序：
1. **订阅次数**（Active用户：12次/年）
2. **TR券**（Pending用户/奖励券：1次）
3. **荔心卷/荔升卷**（积分兑换：1次+趋势追踪）

## 五、nzyy 对接字段

```sql
ALTER TABLE users ADD COLUMN nzyy_status VARCHAR(20);  -- pending / active（预留）
ALTER TABLE users ADD COLUMN nzyy_source VARCHAR(20);  -- nzyy / organic

```

| 字段 | 说明 |
|:---|:---|
| nzyy_status | pending=待激活, active=已激活 |
| nzyy_source | nzyy=从门户来, organic=直接注册 |
| nzyy_expire_at | Pending用户过期时间 |
