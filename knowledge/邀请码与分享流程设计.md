# 邀请码与分享流程设计

> 更新：2026-07-25
> 状态：设计定稿，待实现

---

## 一、核心理念

**邀请码 = 账户的第一次**

- 一个邀请码 = 一个预账户
- 邀请码激活时即创建预账户
- 预账户注册后升级为正式账户
- 邀请码使用后失效，与设备无关

---

## 二、账户体系

### 用户状态

| 状态 | 说明 |
|------|------|
| PENDING | 预账户，激活邀请码后创建，无手机号密码 |
| ACTIVE | 正式账户，注册后升级，拥有完整凭证 |

### 预账户有效期

- 测评完成后开始计时，**2小时**
- 退出时提示有效期
- 超时后自动清理（User + Child + Session）

---

## 三、分享链路

### 三种链接类型

| 类型 | URL | 接收方 | 流程 |
|------|-----|--------|------|
| **邀请注册** | `/register?share=批次ID&slot=激活码` | 新用户 | 分配预账户 → 测评 → 2小时内注册 |
| **邀请孩子自评** | `/assessment/[stage]/student?share=批次ID&slot=码` | 学生 | 直接提交到家长账户 |
| **邀请老师参评** | `/assessment/[stage]/teacher?share=批次ID&slot=码` | 老师 | 直接提交到家长账户 |

### 链接特性

- **一次性**：邀请测评链接提交后失效，不可再用
- **同设备可用**：同一设备可激活多个邀请码（设备与邀请码无绑定）
- **分享链接有效期**：2天

## 四、数据模型

### ShareBatch（分享批次）

老用户一次分享，携带多个 Slot

```prisma
model ShareBatch {
  id          String   @id @default(cuid())
  userId     String   // 分享者
  stageId    String   // 学段
  questionnaireType String // 问卷类型
  slots      Slot[]   // 所有 slot
  createdAt  DateTime @default(now())
  expiresAt  DateTime // 分享链接过期时间
}
```

### Slot（邀请槽位）

每个 Slot 对应一个邀请码或测评机会

```prisma
model Slot {
  id          String   @id @default(cuid())
  batchId    String
  type       String   // register / student / teacher
  code       String   @unique  // 激活码
  usedBy     String?  // 使用者 userId
  usedAt     DateTime?
  childId    String?  // 关联的孩子（测评用）
  expiresAt  DateTime
  createdAt  DateTime @default(now())
}
```

### User

```prisma
model User {
  id            String    @id @default(cuid())
  phone         String?   @unique
  passwordHash  String?
  status        String    @default("PENDING")  // PENDING / ACTIVE
  name          String?
  role          String    @default("PARENT")
  shareBatchId  String?   // 来自哪个分享批次
  children      Child[]
  createdAt     DateTime  @default(now())
  expiresAt     DateTime? // PENDING 状态过期时间
}
```

## 五、邀请码机制

### 邀请码获取

- 用户注册成功后，获得 **10个** 初始邀请码
- 动态生成，存储在用户自己的码池中

### 邀请码使用规则

| 规则 | 说明 |
|------|------|
| 邀请码 = 预账户 | 一个码激活时创建一个预账户 |
| 码只能用一次 | 激活后标记 USED，不可再用 |
| 设备无关 | 不同设备可使用同一邀请码（邀请码维度限制，非设备维度） |

### 梯度补充（建议）

已激活的邀请码数量 = 用户可再分享的数量

```
注册送10个码
    │
    ├── 分享给3个人 → 3个被激活
    │
    ▼
用户可用邀请码 = 10 + 3 = 13 个
```

## 六、完整流程

### 老用户分享

```
老用户登录
    │
    ├── 选择孩子 → 分享孩子自评/老师参评链接
    │        │
    │        └──→ /assessment/[stage]/student?share=批次ID&slot=码
    │
    └── 分享邀请注册链接
             │
             └──→ /register?share=批次ID&slot=激活码
```

### 新用户注册流程

```
打开邀请注册链接
    │
    ├── Slot 未使用 → 分配预账户（PENDING）
    ├── Slot 已使用 → 跳转登录页
    │
    ▼
进入测评 → 完成后2小时倒计时开始
    │
    ▼
情况A：2小时内注册
    │
    ├── 预账户升级为正式账户（ACTIVE）
    ├── 填写手机号+密码
    └── 获得10个新邀请码

情况B：2小时未注册
    │
    ├── 预账户及关联数据清理
    └── 邀请码已使用（不可再用）
```

### 孩子/老师测评流程

```
打开测评链接
    │
    ├── Slot 未使用 → 进入测评
    ├── Slot 已使用 → 提示"链接已失效"
    │
    ▼
填写测评 → 提交
    │
    ▼
结果存入对应孩子的 Session
Slot 标记 USED（链接失效）
```

## 七、安全与限制

| 维度 | 限制 |
|------|------|
| 邀请码格式 | 6位数字 |
| 分享链接有效期 | 2天 |
| 预账户有效期 | 测评完成后2小时 |
| 同一邀请码 | 只能激活一次（与设备无关） |
| 测评链接 | 只能提交一次（一次性） |
